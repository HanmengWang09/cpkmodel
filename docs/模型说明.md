# 模型结构与运行接口

本项目保留原项目截至2026-11-06的完整53状态心肺肾开发模型。生理计算核心由原项目直接提取，仅调整包名称及入口，不重新拟合物理参数。下文索引从0开始。

| 16—17 | Pbar_EP、Pbar_EV | 肾调节感知的动静脉压力 | mmHg |

## 联立计算

血管与心腔按瞬时净流入推进容积，血管压力由压容关系和外压计算；静脉回流受胸膜压及相应非线性阻力影响。四腔容积方程为：

\[
\dot V_{LA}=Q_{PV\to LA}-q_{MV},\quad
\dot V_{LV}=q_{MV}-q_{AV},
\]
\[
\dot V_{RA}=Q_{TV\to RA}-q_{TV},\quad
\dot V_{RV}=q_{TV}-q_{PVL}.
\]

主动心脏通过五壁材料、心包压力与TriSeg几何平衡，计算四腔压力和肌节长度；在每次右端求值时求解当前几何，不增加隐藏历史状态。内部肌节长度与激活量随心相位演化，房室激活存在显式延迟。动态瓣膜由压差、惯性、流动阻力与开闭速率共同决定流量及开度，允许有限反流。

肾模型以瞬时与感知灌注压计算入球阻力、肾小球压力及滤过，包含静脉淤血对Bowman压力的影响。滤过、重吸收、排水与排钠接入体液池；完整体液模型使用动态血浆胶体压、间质交换、淋巴回流、细胞内外渗透分配和保水/保钠反馈。

四腔血量参与总血量、血浆容积、胶体压和钠浓度计算。血管池与四腔血量相加时不把心壁体积作为循环血量。

呼吸模型按四气室流量、顺应性、胸壁和肌压力驱动推进状态。胸膜压随呼吸更新，并进入胸内血管、心腔外压及肺间质压力。心搏和呼吸相位连续演化：

\[
\dot\phi_H=1/T_H,\qquad \dot\phi_R=RR/60.
\]

默认心周期为0.85秒，呼吸频率为12次/分钟；二者共同周期为85秒。累计相位是完整初态的一部分，续算时不清零。

## 外界输入

`configs/default.json` 包含仿真时长、输出间隔、求解设置及以下固定输入：

| 字段 | 默认值 | 单位或含义 |
|---|---|---|
| water_input | 1500/86400 | mL/s，外界水输入 |
| sodium_input | 150/86400 | mmol/s，外界钠输入 |
| filtration_scale | 1 | 滤过容量比例 |
| water_excretion_shift | 0 | 模型排水反馈偏移，无量纲 |
| sodium_excretion_shift | 0 | 模型排钠反馈偏移，无量纲 |
| respiratory_rate | 12 | 次/分钟 |
| muscle_pressure_min | -5 | cmH2O，呼吸肌压力幅度 |

水、钠输入及反馈偏移的实际解释以 `heart_active/boundary.py`、`fluid/kernel.py` 为准。心房压由主动心脏计算，不能作为独立固定输入追加。

`observables.csv` 中GFR和肾血流为mL/min，钠浓度为mmol/L，Q_urine、Q_reabs、Q_return、J_s、J_p、Q_Ls、Q_Lp为mL/s，U_Na为mmol/s，q_mouth为L/s，ppl_mmhg及四腔/心包压力为mmHg，V_b和W为mL。

## 数值实现

`solver.py` 使用SciPy Radau或BDF积分53个物理状态，Numba负责相同方程的快速右端求值，原解析核提供Jacobian及观测。按心搏启动、房室激活、呼吸阶段及外界输入切换时刻分段，在段间连续传递状态；输出网格通过稠密解采样。

默认rtol=1e-8、atol=1e-10、最大步长0.01秒。求解器不添加独立核查积分、检验阈值、通过评分或稳态判定。模型中的有限数、正容积、几何求解和已接受状态边界保护用于处理数值工作域错误；这些保护属于计算内核。

初态文件为 `cpkmodel/data/initial_state.json`，包含状态名称、单位和53个值。可复制后修改并通过 `-InitialState` 传入；改变参数或初态可能产生启动瞬态或超出当前数学工作域。`-Startup` 使用模型构造的原始启动种子。
